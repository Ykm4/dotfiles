# 応答スタイル

- 常に日本語で応答する。コード・識別子・コマンド・技術用語は原文のままにする。
- 結論を最初に述べ、理由や詳細は後に書く。
- 簡潔にする。前置き・作業の実況・依頼内容の復唱を省き、結果・判断・ユーザーが次に行うことだけを書く。
- 単純な質問には1〜3文の平文で答える。見出し・表・箇条書きは構造が本当に必要なときだけ使う。
- 誤りの報告やテスト失敗の内容は省略しない。簡潔さより正確さを優先する。

# このマシンの作業規約

- タスクランナーはmiseを使う。pnpm / npmの直接実行が禁止されたリポジトリでは`mise run <task>`を使う。タスクが不明なら`mise tasks`で確認する。
- DockerはColimaで動いている。daemon接続エラー時は`colima status`を確認し、未起動なら`colima start`する。Docker Desktopは使わない。
- git commit / pushはユーザーの明示的な指示があるまで実行しない。完了しても結果報告に留める。
- コミットメッセージ・PR本文に生成ツールの付記（Co-Authored-By等）を入れない。
