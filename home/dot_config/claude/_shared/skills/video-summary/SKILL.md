# 動画の要約

動画の要約には2つの経路がある。どちらを使うかは、必要な情報が音声にあるか映像にあるかで決める。

| 経路 | 実体 | 向く場面 | 費用 |
|---|---|---|---|
| 字幕 | `summarize` CLI | 会話・講演・対談など、話された内容がすべての動画 | 無料 |
| 映像 | `mise run video:summarize` | スライドの図表、画面のコード、デモの操作手順が要る動画 | 従量（下表） |

字幕が付いていない動画、字幕はあるが図表を指して「これ」「ここ」と話す動画は、字幕経路では意味が取れない。迷ったら映像経路を使う。

## 映像経路

```bash
mise run video:summarize '<YouTube URL>' ['プロンプト'] [--fps 0.2] [--resolution low|default]
```

Gemini が YouTube から直接動画を取得するので、ダウンロードは要らない。既定では映像を毎秒1コマ、低解像度で読む。

- スライド中心の動画は `--fps 0.2` で足りる。画面がほとんど変わらないため、コマ数を減らしても内容は落ちない。
- 手元の動作や細かい文字を追う動画は `--resolution default` に上げる。
- ローカルの動画ファイルも渡せるが、API 側の上限により 15MB までとなる。

出力は本文が標準出力、消費トークンが標準エラーに出る。

### 無料枠の制限

hucomsystem-gws は無料枠で動いており、課金は発生しない。AI Studio で実測した上限は次のとおり。

| 項目 | 上限 |
|---|---|
| 1日のリクエスト数（RPD） | 20 |
| 1分あたりのリクエスト数（RPM） | 5 |
| 1分あたりの入力トークン（TPM） | 25万 |
| YouTube 動画の合計時間 | 1日8時間 |

Flash 系はどのモデルも RPD 20 で並ぶため、モデルを変えても1日の本数は増えない。

実測では `--resolution low` が毎秒およそ96トークンを消費する。TPM 25万に収まるのは1本あたり約40分までなので、それより長い動画は `--fps 0.2` などでコマ数を減らす。

### 費用の目安

無料枠を超えて有料枠へ移した場合の、60分動画1本あたりの概算は次のとおり。

| 設定 | トークン | 概算 |
|---|---|---|
| `--resolution low`（既定） | 36万 | 約 $0.18 |
| `--resolution default` | 108万 | 約 $0.54 |
| `--resolution low --fps 0.2` | 7.2万 | 約 $0.04 |

### 送ってはいけないもの

プロンプトに社内固有の文脈を書かない。案件名・取引先名・社内の判断材料は、無料枠では製品改善に使われ人間のレビュー対象になり得る。

書いてよいのは動画そのものへの指示に限る（「図表を列挙して」「手順を時系列で」など）。動画の内容と社内の事情を突き合わせる作業は、要約が返ってきた後にこの場で行う。有料枠または Vertex AI（`--vertex`）に切り替えれば、この制約は外れる。

## 字幕経路

```bash
summarize '<URL>' --extract --plain
```

抽出された本文をこの場で読んで要約する。`summarize` が未導入なら `brew install summarize` を案内し、導入するかを確かめる。

## 手順

1. 渡された URL と依頼内容から、必要な情報が音声にあるか映像にあるかを判断する。
2. 映像が要るなら `mise run video:summarize` を実行する。スライド中心と分かっていれば `--fps 0.2` を付ける。
3. 字幕で足りるなら `summarize --extract` で本文を取り、この場で要約する。
4. 結果を提示する。ユーザーが社内の文脈と結びつけたい場合は、その突き合わせをこの場で行う。

## 詰まったとき

- `GEMINI_API_KEY が設定されていない` と出たら、キーが未発行か、そのプロファイルに供給されていない。https://aistudio.google.com/apikey で発行し、1Password の hucomsystem Vault 経由で `GEMINI_API_KEY_HUCOM_SYSTEM` として供給する。
- `429` や quota のエラーは無料枠の上限である。1日20本を使い切ったか、長い動画で TPM 25万を超えた可能性がある。`--fps` を下げて試すか、翌日まで待つ。
- 本文が空で `finishReason` が返るときは安全フィルタで止まっている。`--json` で生の応答を確認する。
- 限定公開・非公開の YouTube 動画は API から読めない。公開動画か、ローカルファイルとして渡す。
