# 動画の要約

動画の要約には2つの経路がある。どちらを使うかは、必要な情報が音声にあるか映像にあるかで決める。

| 経路 | 実装 | 向く場面 | 費用 |
|---|---|---|---|
| 字幕 | `summarize`コマンド | 会話・講演・対談など、話された内容がすべての動画 | 無料 |
| 映像 | `mise run video:summarize` | スライドの図表、画面のコード、デモの操作手順が必要な動画 | 無料枠（上限あり） |

字幕が付いていない動画や、字幕はあるが図表を指して「これ」「ここ」と話す動画は、字幕経路では意味が取れない。迷ったら映像経路を使う。

## 映像経路

```bash
mise run video:summarize '<YouTube URL>' ['プロンプト'] [--fps 0.2] [--resolution low|high]
```

GeminiがYouTubeから直接動画を取得するので、ダウンロードは不要である。既定では映像を毎秒1コマ、低解像度で読む。

- スライド中心の動画は画面がほとんど変わらないため、`--fps 0.2`でコマ数を減らしても内容は落ちにくい。
- 手元の動作や細かい文字を追う動画は`--resolution high`に上げる。
- ローカルの動画ファイルは、Gemini APIのFiles APIへアップロードしてから解析する。
- Vertex AIではローカルファイルを直接アップロードできないため、`--vertex`とローカルファイルは併用できない。
- 既定モデルは`gemini-3.7-flash`で、混雑により503が返るときは`--model gemini-3.6-flash`に落とす。
- `gemini-2.5-flash`は新規利用が止まっている。

出力は本文が標準出力、消費トークンが標準エラーに出る。`--json`では本文、使用モデル、入力・出力・思考・合計トークン、入力と出力のモダリティ別内訳をまとめて受け取れる。

実装は公式SDK `@google/genai`を使ったTypeScript（`scripts/summarize.ts`）で、このスキルのディレクトリに同梱してある。初回実行時と依存の更新後に、固定された`bun.lock`を使って依存を導入する。

### 課金と利用上限

hucomsystem-gwsには請求先が設定されておらず、無料枠で動いている。課金は発生せず、上限に達すると429で拒否される。有料枠へ自動的に移行することはない。

AI Studioで確認した上限は次のとおり。

| 項目 | 上限 |
|---|---|
| 1日のリクエスト数（RPD） | 20 |
| 1分あたりのリクエスト数（RPM） | 5 |
| 1分あたりの入力トークン（TPM） | 25万 |
| YouTube 動画の合計時間 | 1日8時間 |

Flash系はどのモデルもRPD 20で同じため、モデルを変えても1日のリクエスト数は増えない。

- TPMは1分あたりの入力トークン上限であり、長い動画がTPM 25万を超える場合は、`--resolution low`を使って`--fps`を下げる。
- RPDはリクエスト回数の上限であり、`--fps`や`--resolution`を変えても消費回数は減らない。
- 失敗したリクエストもRPDを消費することがあるため、この実装は503を自動再試行しない。

YouTube URL機能はプレビュー版で、現在は無料で利用できる。料金とレート制限は変わる可能性があるため、最新情報はhttps://ai.google.dev/gemini-api/docs/video-understandingを確認する。

### 送ってはいけないもの

プロンプトに社内固有の文脈を書かない。案件名・取引先名・社内の判断材料は、無料枠では製品改善に使われ、人間のレビュー対象になり得る。

書いてよいのは動画そのものへの指示に限る（「図表を列挙して」「手順を時系列で」など）。動画の内容と社内の事情を突き合わせる作業は、要約が返ってきた後にこの場で行う。有料枠またはVertex AI（`--vertex`）に切り替えれば、この制約は外れる。

## 字幕経路

```bash
summarize '<URL>' --extract --plain
```

抽出された本文をこの場で読んで要約する。`summarize`が未導入なら`brew install summarize`を案内し、導入するかを確かめる。

## 手順

1. 渡されたURLと依頼内容から、必要な情報が音声にあるか映像にあるかを判断する。
2. 映像が必要なら`mise run video:summarize`を実行し、スライド中心と分かっていれば`--fps 0.2`を付ける。
3. 字幕で足りるなら`summarize --extract`を使い、取り出した本文をこの場で要約する。
4. 結果を提示し、ユーザーが社内の文脈と結びつけたい場合は、その突き合わせをこの場で行う。

## 詰まったとき

- `GEMINI_API_KEY が設定されていない`と出た場合は、https://aistudio.google.com/apikeyでキーを発行し、1Passwordのhucomsystem Vault経由で`GEMINI_API_KEY_HUCOM_SYSTEM`として供給する。
- `429`や割り当て超過のエラーが出た場合は、TPM超過なら`--fps`を下げ、RPD超過なら翌日まで待つ。
- 解析結果が15分以内に返らずタイムアウトした場合は、`--fps`を下げるか、モデルの混雑が収まるまで待ってから再実行する。
- `503`が出た場合は、時間をおいてから手動で再実行する。
- 本文が空の場合は、安全フィルタなどで止まった可能性があるため、表示される理由を確認する。
- 限定公開・非公開のYouTube動画はAPIから読めないため、公開動画かローカルファイルを渡す。
