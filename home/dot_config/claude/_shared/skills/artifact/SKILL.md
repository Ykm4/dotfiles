# アーティファクトを作る

読み手が見て分かる形にする。Markdownでは文章に溶けてしまう構造を、図と表で見せる。

## 読む順序

必要なものだけを読む。全部読まない。

### 必ず読む

- `${CLAUDE_SKILL_DIR}/references/shell.html` — 共通シェル。コピーして起点にする
- `${CLAUDE_SKILL_DIR}/references/authoring.md` — 置換表・エスケープ・Mermaidの書式・公開手順・自己点検
- `~/.claude/rules/design-system.md` — 配色と書体

### 用途に応じて読む

| 作るもの | 読むファイル |
|---|---|
| 実装計画・仕様書の図解 | `${CLAUDE_SKILL_DIR}/references/plan.md` |
| 調査結果・比較検討・集計レポート | `${CLAUDE_SKILL_DIR}/references/research.md` |

### 必要になったときだけ読む

`${CLAUDE_SKILL_DIR}/references/parts.md` — 追加の作図部品。Mermaidに型が無いものをCSSで作る。

次のいずれかが要るときに読む。要らないなら読まない。

- 数値列つきのガントチャート（タスク名・見積り・期間を1つの表で見せる）
- ウォーターフォール（増減の要因分解）
- ランキング・規模比較（横棒つきの表）
- 積み上げ棒（内訳の推移）
- 階段・ステップ（段階的な積み上げ）

## 進め方

- どちらの用途か判断できないときは尋ねる。推測で進めない。
- 元になった資料は書き換えない。成果物はスクラッチパッドに書く。
- 公開したらURLを伝える。
