## 検索対象

~/other/documents/notes/

## タスク

1. 引数のキーワードで notes リポジトリ内を検索
2. ファイル名とファイル内容の両方を検索対象とする
3. マッチしたファイルごとに以下を出力：
   - ファイルパス
   - ファイルの概要（最初の数行 or タイトル）
4. **重要**: 検索結果が0件の場合は「該当するノートは存在しません」と明確に返す。推測や類似候補の提案はしない。

## 出力フォーマット

```
### 検索結果: {件数}件

1. **{ファイルパス}**
   {概要}

2. **{ファイルパス}**
   {概要}
```

または

```
該当するノートは存在しません: "{キーワード}"
```

検索キーワード: $ARGUMENTS
